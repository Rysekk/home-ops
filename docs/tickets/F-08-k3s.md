# F-08: k3s via Ansible

**Refs**: ADR-0003, ADR-0009, ADR-0010 · **Depends on**: F-07

## Acceptance criteria
- [ ] k3s installed through Ansible (the `k3s-io/k3s-ansible` collection or your own role), with the **version pinned** in vars so Renovate can bump it.
- [ ] One server (compute node) and one agent (storage node).
- [ ] Disabled: `flannel-backend=none`, `disable-network-policy`, `disable=traefik,servicelb`. `local-path` stays enabled.
- [ ] `system-reserved` and `kube-reserved` set on the compute node so heavy workloads can't starve the API server.
- [ ] Node labels applied, e.g. `home-ops/role=compute` and `home-ops/role=storage`.
- [ ] The kubeconfig is fetched to the laptop. `kubectl get nodes` shows both nodes as `NotReady`, which is expected because there's no CNI until F-09.
